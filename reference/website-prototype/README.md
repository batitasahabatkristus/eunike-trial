# Yayasan Eunike — Website Redesign Prototype

This is a no-build static prototype, so you can review the visual direction before we turn it into a production Next.js/WordPress implementation.

## Run locally on macOS

```bash
cd /path/to/eunike-redesign
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Alternative with VS Code

Install the "Live Server" extension, open `index.html`, then choose **Open with Live Server**.

## Files

- `index.html` — page structure/content
- `styles.css` — complete responsive brand design
- `script.js` — navigation + subtle reveal interactions
- `assets/` — Eunike logo and photography

## Design direction

- Primary: `#612E8F`
- Pink: `#DD188A`
- Lilac: `#D9C7E1`
- Soft Pink: `#FAD9E8`
- Cream: `#FEECE2`
- Peach: `#FCD3C9`
- Headings: Baloo 2
- Body: Quicksand
- Accent: Parisienne

This first prototype focuses on the homepage experience and information architecture. The program links are intentionally prototype anchors for now.
